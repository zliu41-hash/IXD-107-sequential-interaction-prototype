# Project notes for Claude Code

This repository holds a static GitHub Pages prototype (`index.html` at the root) and the original interaction studies in `studies/`. Keep the study folders unchanged. Saved defaults live in `js/config.js`; the "Tea tuning" panel (`js/panel.js`) edits a live copy of them.

## How to ask questions

Use the AskUserQuestion tool for every question. Do not write questions as a list in your reply. Ask one question at a time and wait for my answer before asking the next. For each question, offer 2–4 suggested answers based on what you found in the studies. I can always pick "Other" to type my own.
